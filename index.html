常见问题

打开时提示「Windows 已保护你的电脑」怎么办？
程序目前未做代码签名，Windows SmartScreen 对未签名程序会显示提示。点击「更多信息」→「仍要运行」即可，这是正常现象，不影响功能。后续可为软件配置代码签名证书消除该提示。
需要安装 .NET 或其它运行环境吗？
不需要。极光录屏以「单文件自包含」方式发布，.NET 运行时与全部依赖都已内嵌在 exe 中，下载后双击即可使用。
支持哪些 Windows 版本？
Windows 10 1809（2018 年 10 月版）及以上均可运行，包括 Windows 11。
收费吗？有广告吗？
完全免费，无广告、无内购、无账号要求。
录制的文件保存在哪里？
默认保存在 exe 所在目录旁的录制文件夹中，每次录制会生成独立文件夹并写入 session.json 元数据。保存位置可在设置页自定义。
会录到我的麦克风声音吗？
默认只录制系统声音（电脑播放的声音）。麦克风是独立开关，默认关闭，需要时在音频设置中打开。
下载文件在国内为什么比较慢？
当前下载走 GitHub Releases，国内网络访问可能偏慢。正式上线后可根据访问情况增加国内镜像节点，加速下载。
